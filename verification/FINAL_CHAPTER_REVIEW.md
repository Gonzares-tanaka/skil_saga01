## 3. 発見した状態遷移バグ

検証範囲でなし。「後で」後の施設退出では確認を繰り返さず、ダンジョンへ出て外から帰還した時に再確認します。「はい」ではアムリタを保持し、最終会話終了後に最終戦へ進みます。ENDING後の再戦防止とNEW GAMEでの初期化も確認しました。

フラグは以下の時点で変化します。

| フラグ | 初期値・変更時点 | 再挑戦 / NEW GAME |
|---|---|---|
| `demon_defeated` | False → デーモン勝利の結果終了時、`Dungeon.defeat_boss()`から取得処理を呼びTrue | 再挑戦でもTrue / NEW GAMEでFalse |
| `has_amrita` | False → 上記取得処理でTrue。真相会話開始時には取得済み。献上・使用・全滅では保持。最終撃破時にFalse | 再挑戦でもTrue / NEW GAMEでFalse |
| `final_event_started` | False → 献上の「はい」でTrue | 再挑戦でもTrue / NEW GAMEでFalse |
| `elysion_barrier_active` | 通常戦闘はFalse。最終戦のBattle生成時にTrue、アムリタ行動実行時にFalse | 新しい最終戦BattleでTrue / NEW GAMEでは最終戦Battleを持たない |
| `lord_of_elysion_defeated` | False → 最終勝利の結果終了時にTrue | 敗北ではFalse / NEW GAMEでFalse |
| `amrita_power_spent` | False → 上記最終勝利時にTrue。使用だけではFalse | 敗北ではFalse / NEW GAMEでFalse |

永続する5フラグは`Dungeon.finale`、バリアはその戦闘の`Battle`に属します。初期化はNEW GAMEの新規オブジェクト生成です。
