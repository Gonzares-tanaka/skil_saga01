# B5 / B10の通常遭遇修正（2026-10-10）

ユーザー指示末尾の正式仕様を採用：**B5・B10は通常ランダム遭遇あり、B15はなし**。冒頭にあった「B15の守護者開始前だけ遭遇あり」は後の指定によって置き換えられたため、実装していない。

## 原因と修正

| 確認項目 | 結果 |
|---|---|
| B5で雑魚敵が出なかった原因 | `Dungeon.move()`の`if self.floor in BOSS_FLOORS: return "", ""`が内部階4を含み、通常探索でも確率抽選へ到達しなかった。 |
| B10で雑魚敵が出なかった原因 | 同じ条件が内部階9も含み、確率抽選を行っていなかった。 |
| B15で雑魚敵が出なかった原因 | 同じ条件が内部階14も含んでいた。ただし、B15の遭遇禁止は最新指定に合う仕様なので維持。 |
| 3フロアで同一原因だったか | 一律のボス階除外が同じ機構だった。B5・B10だけを不具合として修正した。 |
| boss floor判定の修正 | 移動時の遭遇禁止条件を`self.floor == 14`に限定。`BOSS_FLOORS`自体・固定ボス・階層ロック・撃破フラグは変更しない。 |
| encounter tableの不足 | B5・B10の設定は`boss_id`のみで、通常敵候補がなかった。このまま遭遇だけ有効にすると`make_enemies()`で`KeyError: enemy_ids`になる。 |
| 通常敵候補の補完 | `make_enemies(boss=False)`で通常候補がないボス階は直前階を参照。B5→B4、B10→B9の既存候補・重み・編成数・HP/STR/INT倍率をそのまま使用。討伐QUESTが既に使っている参照方式と一致する。専用の新敵・新倍率は追加しない。 |
| ボス撃破前後 | 遭遇判定は`defeated_bosses`を見ない。B5・B10の撃破前後で同じ通常遭遇処理。固定ボスが再出現しない既存処理は維持。 |
| ボス戦中の遭遇禁止 | 探索の移動処理は`state == "explore"`でのみ実行。ボス会話・コマンド入力・戦闘解決中には呼ばれない。 |
| B15守護者開始前 | 最新指定どおり、通常遭遇なし。開始前だけ有効にする処理は追加していない。 |
| B15守護者開始後 | 連戦中、連戦間、泉、デーモンまで、撃破後も通常遭遇なし。B15を歩いても遭遇用の乱数抽選をしない。 |
| B15のQUEST | シンボル描画・調査・討伐接触は通常ランダム遭遇と別処理。探索1、調査3、討伐1が引き続き生成・SAVE/LOAD可能。討伐の専用戦闘は開始できる。 |

B5の通常敵はB4の`golem / skeleton / mage / wisp`、重み`5 / 3 / 4 / 1`、2～3体、HP/攻撃倍率1.3。B10はB9の`iron_golem / berserker / assassin / stone_beast`、同重み、2～3体、倍率1.0。これは既存値の再利用で、今回のバランス調整ではない。

| D：B9 | 通常遭遇あり。 |

通常モード・DEBUGモードを検証。B5・B10は安全2歩中に遭遇抽選せず、以降の乱数値が設定確率未満の場合だけ遭遇する。B15は乱数を0に強制しても抽選自体をしない。B5/B10とB4/B9を同じ乱数状態から生成すると敵の全属性が一致することも確認した。

## 変更範囲

- ゲーム本体：`rpg/dungeon.py`の移動時の遭遇除外と通常敵生成のみ。
- 検証：`tests/test_dungeon.py`, `tests/test_finale.py`, `tools/verify_web_build.py`, `tools/verify_final_chapter.py`。
- 説明：README、本報告、QUEST調査報告への追記。
- 配布：最新の`dist/game.html`とGKDコピー用ZIP。

今回、`data/*.json`・`.pyxres`・`.pyxpal`・音声・画像・敵能力・遭遇率・ボス能力・TRZ・成長率・SKILL・SAVE仕様は変更していない。B15補助QUEST座標は前の修正のまま。B15の通常遭遇禁止とQUEST対応は独立した仕様として維持する。
