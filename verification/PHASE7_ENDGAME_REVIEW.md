## 2. スタッフロールの実装方法

`PostgameMixin`に以下の独立状態を追加しました。

```text
既存ENDING → credits → ending_end
                         ├ 初回：extra_quest_title → extra_quest_story → TITLE
                         └ 再クリア：TITLE
```

既存の暗い色0を背景、明るい色3を文字に使用し、実際の文字幅から各行のX座標を計算しています。長い行は自動改行します。空行も保持し、下から上へ1ピクセルずつスクロールします。

現データは33行・行間12ピクセル・1ピクセル3フレーム、30FPSで約**51.6秒**です。初回はスキップ不可、再クリアではAでスキップできます。終了判定は演出フレームだけで行い、音声の再生状態を条件にしていません。

## 5. スタッフロールの編集方法

| 項目 | 編集内容 |

JSONの配列・引用符などの形式を維持し、ゲームを再起動すると読み直します。描画位置の個別修正は不要です。Web／GKDへ反映するときは配布物を再ビルドします。

## 6. 専用BGMの実装方法

`assets/postgame.pyxres`の**Music 0**を新しい`bgm_credits`へ割り当てました。他のリソースのMusic 0とは別です。既存曲は上書きしていません。

短いファンファーレだけの反復を避け、祝福の導入4小節 → 主題16小節 → 展開16小節 → ブリッジ12小節 → 再現と終止16小節の64小節で構成しました。メロディー・伴奏・低音の3声を使用し、最後は終止音から休符へつなげます。データ上の全長は約**52.0秒**で、スタッフロール終了の約51.6秒は最後の休符区間に入ります。

チャンネル0は既存SE用に空け、1＝旋律、2＝伴奏、3＝低音です。再生は既存AudioManagerを利用し、ネイティブ版の`playm()`停止回避経路も維持しています。曲終了・チャンネル停止を待つ処理は追加していません。スクロール終了時に曲を停止し、無音でもENDへ進みます。

## 8. END表示とEXTRA QUEST告知

スタッフロールの一行として流すのではなく、別状態へ切り替えて大きい**END**を中央に3秒表示します。その後、初回のみ**EXTRA QUEST／古代竜の目覚め**と案内文章を表示し、Aでタイトルへ進みます。ゲーム内の解放告知に竜の座標・攻略方法は書いていません。

再クリアではENDからタイトルへ直接戻り、解放告知を繰り返しません。専用ページは入力をいったん離してからの新規押下を受け付け、前画面の押しっぱなしによるページ飛ばしを防ぎます。

## 9. クリアフラグの保存方式

`CompletionRecords`を通常セーブの省略可能な`completion`項目へ保存します。

```text
run_id
main_game_cleared
ancient_dragon_defeated
ancient_dragon_best_turns
ancient_dragon_victories
```

ロードオブエリシオン勝利時、**今回の最終戦直前チェックポイントから、切り離した保存用コピーを作成・検証し、通常SAVEと同じバックエンドへ記録してから**既存ENDINGへ進みます。手動SAVEは不要です。保存先・通常セーブのversion 1は変更していません。

保存失敗時は「クリア記録は未保存です」と明示する画面に止まり、Aで再試行できます。以前の保存データ・戦闘直前チェックポイントは保持します。成功前にクリアフラグを確定せず、同じペイロードを再試行するため、再試行で竜の討伐回数が二重加算されることもありません。

本編勝利と竜勝利に限る自動記録であり、通常探索の定期オートセーブを追加したものではありません。

## 10. エンディング後の再開方式

タイトルの「つづきから」で、次の状態のHUBへ戻ります。

| 項目 | 再開時 |
|---|---|
| 育成・所持スキル・Uses・アイテム | **その回の**最終戦直前へ復元 |
| 本編クリア記録 | ON |
| デーモン | 撃破済み |
| アムリタ | 所持 |
| 最終イベント／本編ボス撃破／アムリタ消費の進行フラグ | 最終戦へ再挑戦できる状態へ戻す |
| 拠点5施設・探索・QUEST | 通常利用可能 |
| 竜の討伐記録 | 維持 |

最終戦のチェックポイントと永続クリア記録を分離しました。再戦時は新しいチェックポイントを取得するため、クリア後に育てたスキル・能力を初回クリア時へ戻しません。

ENDING中にアプリ終了／ブラウザ再読込しても、通常セーブには既にHUB再開データがあります。途中のスタッフロールへ復帰する方式ではなく、安全な拠点からCONTINUEします。実行中の既存ENDING自体は従来の結末フラグ・文章を保持しています。

## 11. 既存セーブとの互換性

新項目がない旧セーブは未クリアとして読み込みます。旧データのスキル・TRZ・道具・クエスト履歴は既存処理で復元します。NEW GAMEはクリア記録OFF、新しい冒険IDで開始します。通常／中断の保存形式version・保存先は維持しています。

古い中断が記録を巻き戻すケースには次の対策を入れました。

- 同じ冒険IDのクリア後中断を復元するときは、通常セーブのクリア・竜記録も照合し、クリアをOR、最短を小さい値、回数を大きい値で統合します。
- 同じ冒険の**クリア前中断**が残っている場合は消費せず、「つづきから」を使うよう案内します。
- 冒険IDを持たない旧中断とクリア済み通常セーブの組合せも、所属を判定できないため中断を消費せず案内します。
- 別の冒険IDへ以前のクリア記録を移しません。NEW GAMEでクリア状態を引き継ぐことはありません。
- 不正な型・矛盾した記録はエラーとし、既存の読み込み保護を維持します。

旧通常セーブの読み込みは確認済みです。新しい竜データを持つセーブを旧プログラムへ戻す方向の互換性までは保証していません。実ユーザーのセーブ／中断は検証で上書き・削除・消費していません。

## 14. 討伐ターン数の計測方法

既存の`Battle.round`を、竜のVICTORY確定時にそのまま取得します。画面表示フレーム、行動回数、撃破後のメッセージ数はターンに加算しません。敗北・逃走では勝利記録を更新しません。

テストでは指定した戦闘ラウンド値が保存・表示へ渡ることを確認し、実戦モデルの勝利でも記録しました。PC実描画検証の討伐は27ターンです。

## 15. 最短記録の保存方法

勝利時に`ancient_dragon_victories`を1増やし、`ancient_dragon_defeated=True`、最短記録を`min(前回最短, 今回ターン)`へ更新します。初勝利は今回値を設定します。

現在の育成状態・竜の記録・拠点へ帰還可能な状態を切り離したコピーから通常セーブへ自動記録してから、結果演出を表示します。保存失敗時は本編クリアと同じ再試行画面です。ロードオブエリシオン再戦用チェックポイントから竜記録を巻き戻す処理はありません。

クリア後はギルドのクエスト記録画面でAを押すと、本編クリア／竜の討伐状況／最短ターン／討伐回数を確認できます。Bで元の記録画面へ戻ります。本編未クリア時にはこの画面から竜の存在を明かしません。

## 16. 初回撃破と再戦時の演出

初回は専用文章 → **「あなたこそ真の SKILL SEEKERSだ！」** → 今回ターン・BEST RECORD・更新時NEW RECORD → 拠点帰還です。2回目以降は文章・称号を繰り返さず結果へ進みます。

結果画面でAを押すと既存の帰還・清算処理からHUBへ戻ります。HP回復とTRZ確定は通常帰還の経路を使い、技Usesや道具を無条件に補充する追加処理はありません。この帰還直後は献上確認を重ねて表示せず、自由な拠点操作に戻します。

同じ場所のシンボルは残り、準備・確認後に何度でも再戦できます。ドラゴン再戦の条件に本編ボス再撃破はありません。

## 17. ロードオブエリシオン再戦時の動作

CONTINUE直後は自由なHUBです。以後の既存の拠点再入場条件で献上確認を受け、最終イベントから再挑戦できます。アムリタを使用して障壁を解除する本編戦闘の仕様は維持しています。

再クリア時も既存ENDING → 専用曲のスタッフロール → END → TITLEです。スタッフロールはAスキップ可、EXTRA QUEST告知はありません。今回の戦闘直前を基準に復元し、クリア後に増えた能力・スキルと竜の記録を保持することをテストしました。

既存最終章回帰では、全滅A～Eの5回連続再挑戦、Uses・ITEM・アムリタ・障壁の復元も成功しています。通常全滅へ最終戦チェックポイントを適用しないことも確認しました。

## 21. 実機未確認事項・残る確認点

- iPhoneの実Safariで、ロック・解除・アプリ切替を行った場合の音声復帰と操作は未確認です。音声を使用不可にした実ブラウザ回帰は成功しています。
- GKD Pixel 2実機での新曲・新画像の表示、SELECT終了、保存先権限、通常／診断版の長時間動作は未確認です。配布物・構文・ネイティブAPI経路は確認しています。
- 専用BGMの実機スピーカーでの音量・聴感、スタッフロールの読みやすい速度はプレイテストで最終確認してください。
- 竜の難易度は仮定パーティを使った検証です。自然育成したクリアデータで、育成時間・Uses消費と合わせた評価が必要です。
- エンディング途中のアプリ終了からは、保存済みの拠点へCONTINUEします。演出の途中位置を保存して再開する機能は追加していません。
- 既存の全ユーザー画像の原著作者・制作経緯までは再確認できていません。今回追加した第三者クレジットは、確認できたフォント・Pyxelに限っています。

確認済み範囲で、進行不能・セーブ巻戻り・再挑戦不能の残存は見つかっていません。実機未実施の項目を「確認済み」とは扱っていません。
